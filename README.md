
Calendário pessoal desenvolvido para organizar tarefas, compromissos e rotina de forma simples e visual.

O projeto foi criado com foco em produtividade, organização e facilidade de uso, com suporte a diferentes visualizações do calendário e armazenamento local dos dados no navegador.

## Funcionalidades

- Visualização por dia, semana e mês
- Criação de tarefas e compromissos
- Definição de horários, cores e observações
- Marcação de tarefas como concluídas
- Destaque para tarefas importantes
- Filtros por tipo de item
- Resumo diário
- Modo claro e modo escuro
- Exportação e importação de backup
- Armazenamento local utilizando LocalStorage
- Layout responsivo
- Acesso ao Instagram da FFL pelo próprio sistema

## Tecnologias utilizadas 

- HTML
- CSS
- JavaScript
- LocalStorage
- Git e GitHub
- GitHub Pages
